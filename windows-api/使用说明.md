# Qwen3-VL 道路图片描述

## 使用

双击本目录中的 **开始描述.cmd**，选择一张 JPG、PNG、WebP 或 BMP 图片。脚本会自动启动本地 Ollama 服务，默认只在窗口中输出适合朗读的中文描述。

第一次推理需要加载模型，通常比后续推理慢。重启电脑后仍可通过同一个入口运行。

命令行使用：在本目录打开 PowerShell，执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ".\02-描述道路图片.ps1" -ImagePath "C:\照片\road.jpg"
```

如需把 JSON 保存到图片旁边，在命令末尾加 `-SaveJson`。

调试时可加 `-ShowJson` 显示完整 JSON，或加 `-ShowMetrics` 显示端到端耗时、生成速度和模型显存占用。

## 局域网 API

需要让同一局域网内的其他设备调用 Ollama API 时，双击 `启动局域网API.cmd`。首次使用或连接失败时，再双击 `添加防火墙规则.cmd`。详细调用方式见 `局域网API说明.md`。

使用结束后可双击 `恢复仅本机模式.cmd`，让服务重新只接受本机连接。

## 配置

- 模型：`qwen3-vl:8b-instruct-q4_K_M`
- 运行程序：本目录 `runtime` 中的官方 Ollama Windows 独立版
- 模型文件：本目录 `models`
- 服务：`http://127.0.0.1:11434`，仅本机访问
- 上下文：6144；并发：1；启用 Flash Attention；关闭云功能
- 服务日志：本目录 `logs`
- 环境变量仅应用于脚本及其启动的服务进程。

不需要安装 Python、PyTorch 或单独的 CUDA Toolkit。请保留整个目录，尤其是 `runtime` 和 `models`。

可在本目录运行以下命令查看模型是否使用 GPU：

```powershell
.\runtime\ollama.exe ps
nvidia-smi
```

## 范围

本工具描述单张图片，不验证现实道路是否可安全通行。环境安装验证不等于真实道路场景的准确率评测。

官方资料：[Ollama Windows](https://docs.ollama.com/windows)、[模型页面](https://ollama.com/library/qwen3-vl:8b-instruct-q4_K_M)。
